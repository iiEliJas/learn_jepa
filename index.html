Learn LeJEPA by playing with it.

Static, dependency-free demos that turn the equations and the training logs into things you can drag, click, and inspect. Start with the objective, then look at where the trained CIFAR-10 model puts its embeddings.

What is next

Uses the CIFAR export

The atlas and per-image card are available. Their shared export (cifar_atlas/atlas_data.js) also feeds the next demos: three-space lens, real-data SIGReg inspector, 16-D inspector, forward-pass x-ray, attention explorer and augmentation playground.

No checkpoint needed

The collapse simulator, a guided tour of JEPA itself, and a run comparator can be built with the existing logs and a tiny CPU training loop.

How the static pages work

Open index.html directly, or serve this folder with python -m http.server. No CDN, no build step, no runtime server. The math is the same as pysrc/lejepa/sigreg.py.

Why this exists

The experiment reports already have good static figures, but a static PCA plot cannot answer “which image is this point?” or “what happens if I make the cloud narrower?”. These pages are the interactive layer around the PyTorch ground truth: every panel shows the formula, the current numbers, and a control that changes them.

The training code, the C/CUDA kernels, the protocol and the benchmark numbers live in fast_JEPA. This repository only turns that work into learning material.

The demos are learning material, not benchmarks. The trained-checkpoint numbers in the experiment log remain the source of truth for claims about the model.
