Learn LeJEPA by playing with it.

Static, dependency-free demos that turn the equations and the training logs into things you can drag, click and inspect. Start with the objective, then look at where the trained CIFAR-10 model puts its embeddings.

Part 1. The objective

1

The loss, by hand

LeJEPA trains an encoder with two terms: a prediction loss that pulls the views of one image together, and SIGReg, which keeps the whole batch of embeddings spread out. Edit a tiny tensor of embeddings and see both terms, and λ, respond.

Open the loss calculatorNo checkpoint needed
2

SIGReg, visually

SIGReg compares the embedding cloud with a standard Gaussian by looking at it through many random one-dimensional slices. Draw a cloud, project it, and watch the statistic and its gradient push points outward.

Open SIGReg LabNo checkpoint needed
3

Collapse, in front of you

Without the regularizer, the easiest way to make views agree is to map everything to the same place. Train a tiny encoder in the browser, switch SIGReg off, and watch the effective rank fall while the prediction loss still improves.

Open the simulatorNo checkpoint needed

About the demos

Real model outputs

The CIFAR demos read a 2,000-image test subset exported from the 400-epoch run. CLS, proj_head and projector vectors are the model’s own; the checkpoint is a release asset, not a committed file.

Static by design

Every page is a classic script with no CDN, bundler or runtime server. Open index.html from disk, or serve the folder with python3 -m http.server.

Math you can check

The JavaScript cores are tested against the PyTorch reference: SIGReg quadrature, the loss terms, neighbour metrics and the toy gradients. Run the tests.

These pages are learning material, not benchmarks. The experiment log in fast_JEPA remains the source of truth for claims about the model.
