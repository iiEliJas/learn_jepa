SIGReg estimator

What is happening?

μ is the mean of the first V_g views. The prediction loss is the mean squared distance from every view to μ. SIGReg tests each view against N(0, I).

μ[n] = mean_{v < V_g} z[v,n] L_pred = mean_{v,n,k} (μ[n,k] − z[v,n,k])² L = (1−λ)·L_pred + λ·L_SIGReg

The paper and the official minimal example use mean_over_k, not a sum over coordinates. Switching to sum_over_k multiplies L_pred by K and silently changes the effective lambda.

L_pred – mean over V·N·K
L_SIGReg – mean over views
total loss – λ = 0.020
SIGReg share – λ·L_sig / L
per-view range – min … max

Step by step

What each symbol means

V views per image, N images (samples), K projector dimensions, V_g global views used for the target mean. The official small-scale recipe uses V=4, V_g=4; the large-scale recipe uses V_g=2 global views plus local views.

Per-view SIGReg

In per_view mode each view is tested over its N samples, then the values are averaged. In joint mode all V·N points go through one test.

Try this

1. Collapse. Use the “Collapsed” preset. Every view is identical, so L_pred = 0, but L_SIGReg is large.

2. Make views noisy. Use “Noisy views”. The prediction term rises; SIGReg may fall because the marginal cloud is wider.

3. Move lambda. Drag it to 0 and then 0.2. At λ=0 the total is pure prediction; at λ=0.2 the regularizer dominates.

4. Change V_g. With V_g < V the target mean ignores the local views, but they still contribute to L_pred and SIGReg.

5. Switch reduction. Compare mean-over-K and sum-over-K. The loss changes by a factor of K; that is why lambda values are not portable between conventions.

Reference: pysrc/lejepa/loss.py and protocol section 5.1. SIGReg uses the same one-sided 17-knot quadrature as pysrc/lejepa/sigreg.py.
