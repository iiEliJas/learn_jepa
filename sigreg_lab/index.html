What am I looking at?

SIGReg samples directions a_s on the unit circle, projects every point xj to t·(a_s·xj), and compares the empirical characteristic function with the Gaussian one.

T_s = N · Σ_t [(C(t) − φ₀(t))² + S(t)²] · w(t) L_SIGReg = mean_s T_s φ₀(t) = exp(−t²/2), w(t) = exp(−t²/2)

The quadrature is one-sided on [0, t_max], with doubled interior weights. A Gaussian batch has expected L_SIGReg ≈ 1.05 for this grid, not 0.

How to read this table

At small t the statistic is sensitive to mean and scale; at larger t it is sensitive to shape. The weight already contains the Gaussian window and the trapezoid spacing, so the last column is directly summable. The same formula appears in pysrc/lejepa/sigreg.py.

Try this

1. Collapse it. Choose the “Collapsed” preset. The cloud shrinks and L_SIGReg rises far above the null. The arrows point outward.

2. Stretch it. Set std x = 2.5 and std y = 0.25. The marginal along x is too wide, along y too narrow; both contribute.

3. Shift it. Keep the shape Gaussian but move the mean. SIGReg is not mean-invariant, because the target is N(0,1), not a standardized Gaussian.

4. Resample directions. The value moves. With few slices the estimator is noisy; this is why the paper resamples every step. Even a true Gaussian batch scatters: at N = 256, K = 2, S = 64 the 5–95% range is roughly 0.4 … 2.2 around the 1.05 null. Judge a cloud against that spread, not against a single number.

Why this matters for LeJEPA

The prediction term alone can be driven to zero by making all embeddings equal. SIGReg makes that collapsed cloud expensive: its 1-D projections are a spike at zero, while the target is a standard normal.

In the real model SIGReg is computed once on a (V, N, K) tensor, so every view shares the same directions. The slice count and t_max are config values, not constants.

A value near 1.05 is the Gaussian expectation for this quadrature, not a perfect zero. The trained CIFAR run reported L_sig ≈ 2.47, which is above the null but far below a collapsed cloud.
Exact conventions: one-sided quadrature on [0, t_max], n_knots odd, endpoint weights dt, interior 2·dt, times exp(−t²/2). Reference: pysrc/lejepa/sigreg.py · protocol section 5.2.
