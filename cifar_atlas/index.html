What am I looking at?

Each dot is one test image. The same image appears in three learned spaces: the raw ViT CLS token, the 512-d proj_head used by the probe, and the 16-d projector output used by the prediction loss and SIGReg.

raw cosine: zᵀx / (‖z‖‖x‖) centered: (z − μ)ᵀ(x − μ) / (‖z − μ‖‖x − μ‖) μ = mean feature over the subset

The raw ViT features have a large common mean direction. Raw cosine then looks high for almost every pair; centring removes that direction before comparing.

How the probe and projector differ

The probe is a small LayerNorm + Linear head on the 512-d feature, trained with labels. The projector is a 512 → 512 → 16 MLP trained by the LeJEPA objective. The probe is allowed to be semantic; the projector is asked to be predictable across views and close to N(0, I) in every random slice.

That is why the 16-d projector can have a lower effective rank and a more diffuse class geometry than the 512-d head, while still being the space where L_pred and SIGReg are measured.

What the confusion cell shows

A cell is not necessarily a “hard class”. It is a joint event: true label y and predicted label ŷ. The thumbnail strip is the evidence for that cell. Use it to check whether the error is a genuine semantic confusion or a single odd image.

The atlas uses the test split only. The 512-d probe feature is the same one the training run evaluates; all embeddings are produced in eval mode, so the projector's BatchNorm uses running statistics.
